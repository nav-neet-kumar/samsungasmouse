# Navneet's Link Hub

A lightweight public page collecting my websites, projects, and useful links.

## Run locally
Open `index.html` in a modern browser. No build step, framework, dependencies, or API keys are required.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. GitHub will show the public URL when the site is published.

The page is static and contains links only. Do not add credentials or private URLs to this public repository.
